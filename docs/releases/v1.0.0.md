# Stashd v1.0.0 release notes (draft)

Stashd 1.0 establishes the complete preservation flow: create a **Stash**,
preserve canonical media in the **Vault**, and publish rebuildable
**Broadcasts**.

- UI-v2 provides Stashes, Vault, Broadcasts, Status, Configure, Connections,
  API tokens, and declaration-driven plugin credentials.
- First run creates one owner account; normal use requires login.
- Plugins are explicit, versioned OCI installs. YouTube 0.3.9 is the supported
  first-party Input plugin release for this candidate.
- Upgrades must take a PostgreSQL backup first. This release removes legacy
  Broadcast token columns and SponsorBlock data, so rollback requires both the
  previous image and restoration of the pre-upgrade database backup.
